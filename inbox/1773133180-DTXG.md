# Arel snippet

## Snippet
```ruby
scope :has_initial_odometer_reading, (lambda do
  readings = Dependencies['models.odometer_readings']
  initial_readings = readings.arel_table.alias('initial_readings')
  reading_belongs_to_charge_order = initial_readings[:charge_order_id].eq(arel_table[:id])
  is_initial_type = initial_readings[:reading_type].eq(readings.reading_types[:initial])

  joins(arel_table.join(initial_readings)
    .on(reading_belongs_to_charge_order
        .and(is_initial_type))
    .join_sources)
end)

scope :with_latest_reading, (lambda do
  # `has_one :latest_odometer_reading` doesn't use LIMIT in the query so, in order
  # to joins with only the latest odometer reading, an alias table is necessary
  readings = Dependencies['models.odometer_readings'].arel_table
  later_reading = readings.alias('later_reading')
  reading_belongs_to_charge_order = later_reading[:charge_order_id].eq(arel_table[:id])
  later_reading_is_later_than_reading = later_reading[:day].gt(readings[:day])
  there_is_no_later_reading = later_reading[:id].eq(nil)

  joins(:odometer_readings)
    .joins(
      arel_table.join(later_reading, Arel::Nodes::OuterJoin)
      .on(reading_belongs_to_charge_order
          .and(later_reading_is_later_than_reading))
      .join_sources
    )
    .where(there_is_no_later_reading)
end)

def charge_order_ids(date) # rubocop:disable Metrics/AbcSize
  Dependencies['models.odometer_readings'].arel_table
  on_time_start = Date.new(date.year, date.month, ON_TIME_READING_START_DAY)
  auto_type = Dependencies['models.odometer_readings'].reading_types[:auto_submission]

  Dependencies['models.charge_orders']
    .auto_odometer_submit_status_opted_in
    .live_on(date)
    .has_initial_odometer_reading
    .with_latest_reading
    .where(odometer_readings: { day: ...on_time_start })
    .where.not(odometer_readings: { day: date.beginning_of_month.., reading_type: auto_type })
    .distinct
    .ids
end
```

## Context
- I was tasked with creating a query that finds all the IDs of charge orders that:
  - Have an initial odometer reading (`Dependencies['models.odometer_readings'].reading_types[:initial]`)
  - AND:
    - Hasn't had a reading this month
    - OR it's last reading was before the 19th AND was not an autosubmission

- This query needed to avoid using raw SQL because ✨ ***Rails*** ✨ and avoid
  using a subquery for performance reasons.
- To do this I need two separate joins on odometer readings:
  - An initial odometer reading
  - The last odometer reading
    - And just for increased difficulty, finding the last of something requires
      an anti-join, which will need _another_ table
- Enter `.arel_table` and `.arel_table.alias`
  - I believe Arel tables are what is used, behind-the-scenes, for `ActiveRecord`
  - The alias method creates a separate, duplicated arel table to allow for
    queries that don't interfere with each other.

- So, I create an alias for initial odometer readings, and another alias for the
  anti-join
  - The anti-join works like this:
    - OG table = readings
    - aliased table = later_readings
    - later_readings = where later_readings.day > readings.day
    - join the two tables
    - if a reading has no later reading, then it is the last one

- I stick all that in a scope, pull it in, then I can query on
  `odometer_readings`, knowing that it's only the last reading for each order
