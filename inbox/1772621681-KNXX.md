# New keymaps

## LSP (<leader>l)
- `<leader>la` — Code action (moved from <leader>df)
- `<leader>lh` — Hover documentation
- `<leader>li` — Incoming calls
- `<leader>lo` — Outgoing calls
- `<leader>lr` — Rename symbol
- `<leader>ls` — Signature help
- `<leader>lt` — Type definition
- `<leader>lw` — Workspace symbols

## Flash
- `gs` — Flash jump (normal, visual, operator-pending)
- `gS` — Flash treesitter select
- `r` — Remote flash (operator-pending only, e.g. yr to yank from a remote location)

## Treesitter textobjects
- `af/if` — Around/inside function
- `ac/ic` — Around/inside class
- `aa/ia` — Around/inside argument
- `ai/ii` — Around/inside conditional
- `al/il` — Around/inside loop
- `]m/[m` — Next/previous method start
- `]M/[M` — Next/previous method end
- `]]/[[` — Next/previous class start
- `<leader>sa` — Swap argument with next
- `<leader>sA` — Swap argument with previous

## Search/replace
- `<leader>sr` — Grug-far project-wide find/replace (works in visual mode too)
